# This is a VENDORED COPY of the manifest that ships in cloudgrid at
# services/catalyst/mcp/internal/toolset/tools.go. It exists so this repo can
# gate its prose without reaching across a repository boundary in CI.
#
# Why it needs a gate at all: a skill is prose a model acts on. A skill naming a
# tool that does not exist does not crash — the model calls it, gets "unknown
# tool", and improvises. And a tool that ships with no skill mentioning it is
# invisible: the model never learns it is there. Both are silent.
#
# Regenerate from a cloudgrid checkout:
#
#   git -C <cloudgrid> show origin/main:services/catalyst/mcp/internal/toolset/tools.go \
#     | grep -o 'Name:[[:space:]]*"catalyst_[a-z_]*"' \
#     | grep -o 'catalyst_[a-z_]*' | sort -u
