# The curated Catalyst MCP tool surface.
#
# A copy of the tool names the Catalyst MCP server returns from `tools/list`, one
# per line. It exists so this repo can check its prose against the tools that
# really ship, without calling the server from CI.
#
# Why it needs a check at all: a skill is prose a model acts on. A skill naming a
# tool that does not exist does not crash — the model calls it, gets "unknown
# tool", and improvises. And a tool that ships with no skill mentioning it is
# invisible: the model never learns it is there. Both are silent.
#
# Update it whenever the server's tool list changes: the lines below must equal
# the names `tools/list` returns, sorted. A write tool is absent from `tools/list`
# for a caller whose role cannot write, so take the list as a caller who can.
#
