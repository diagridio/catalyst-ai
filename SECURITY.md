# Security policy

## Reporting a vulnerability

Please don't open a public issue for a security problem.

Report it privately through GitHub instead: on this repository's **Security** tab, choose
**Report a vulnerability**. Only the maintainers can see the report, and we'll reply there.

Include what you found, how to reproduce it, and which skill, script or version it affects.

## Scope

This repository holds skills, scripts and plugin metadata. A problem in the Diagrid
Catalyst service, the `diagrid` CLI or the Catalyst MCP server itself is still welcome
here, and we'll route it to the right team.
